Methodology & caveats

  • Window: requests created in the last 90 days, pulled fresh every night by a GitHub Action.
  • Median days to close uses closed requests only. Requests still open aren't counted, which makes slow cities look faster than they are, so check the open count and the % columns too.
  • % closed within 7 / 30 days counts every request at least 7 (or 30) days old, open or closed, so open cases count against the city.
  • Requests per 1,000 residents uses U.S. Census Bureau Vintage 2025 population estimates.
  • "Closed" isn't always "fixed". Cities close cases as duplicates, referrals to another agency, or "no issue found", sometimes automatically. LA's "Report a Sidewalk Problem" cases, for example, close almost instantly because they're routed to another program. The same-day % column helps flag this.
  • Categories differ by city. Los Angeles: Street Pavement Issues → potholes & pavement, Streetlight Repair Services → streetlights, Illegal Dumping Item Pickup → dumping, Graffiti Removal → graffiti, Report a Sidewalk Problem + Curb Issues → sidewalks & curbs. SeeClickFix cities: we match each report's request type and title by keyword.
  • SeeClickFix cities show resident reports made through the SeeClickFix app. Most LA and OC cities don't use it as their official system, so volumes are small and may not be representative. Cities with fewer than 30 matching requests are listed but not ranked.
  • No addresses. We publish only aggregates. Raw records stay with the city.
  • Sources: MyLA311 Cases 2026, SeeClickFix API v2, Census population estimates. Code: github.com/structorio/la-fix-tracker.
